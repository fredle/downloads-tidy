# Store listing: Downloads Tidy

## Product name

Downloads Tidy

## Short description

Sort your Downloads folder with rules. Preview first, undo any time.

## Description

Your Downloads folder is a dumping ground: installers you ran once, zip files, PDFs, screenshots. Windows Storage Sense can only delete files by age, permanently, and it never sorts anything. The alternative has been writing PowerShell scripts or living with the mess.

Downloads Tidy fixes this with simple rules. Say which file types, how old and how large, and choose what happens: move into a subfolder, or send to the Recycle Bin. Six ready-made rules cover installers, archives, documents, images and media.

Nothing happens by surprise. The Preview tab shows every file, where it would go and which rule picked it. Only when you click Tidy now do files move. Made a mistake? The Undo tab puts the whole last run back, or just the files you pick. Files are never permanently deleted, and existing files are never overwritten.

Want it hands-off? Turn on the schedule and Downloads Tidy runs while the app is open or minimised. It leaves alone anything modified in the last few minutes, anything still downloading, and anything open in another program, so it will not grab a file mid-download.

It works on any folder, including a Downloads folder you have moved to another drive.

Private by design: no accounts, no telemetry, no admin rights. Your files and file names stay on your PC. The only network use is an optional daily check for app updates.

## Product features

- Rules by file type, age and size
- Move files into subfolders or send them to the Recycle Bin
- Dry-run preview of every change before anything happens
- One-click undo of the whole last run
- Restore individual files from the undo log
- Never overwrites: name clashes become "file (1).pdf"
- Never permanently deletes anything
- Skips files modified in the last N minutes
- Skips files that are still downloading or open elsewhere
- Optional scheduled runs while the app is open
- Works on any folder, including a relocated Downloads folder
- One-click presets for image, document, archive, installer, video and audio types
- Reorderable rules; the first match wins
- Keyboard shortcuts: F5, Ctrl+Enter, Ctrl+Z
- No telemetry, no accounts, no admin rights
- Automatic updates that you can switch off

## Privacy

Stored locally in `%LOCALAPPDATA%\DownloadsTidy\`: your settings (folder, rules, schedule, update preference) and a log of the last tidy run so it can be undone. Nothing is uploaded.

Network: the app checks GitHub Releases for new versions about once a day (can be turned off in the app footer). No file names, paths or usage data are sent. No telemetry, no accounts, no admin rights.
