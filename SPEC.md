# Downloads Tidy

Rule-based Downloads folder sorter with preview and one-click undo.

## Problem

Downloads fills up with installers, zips, PDFs and images. Windows Storage Sense can only delete by age, permanently, and does not sort. People write PowerShell scripts or live with the mess.

## Features (1.0)

- Rules by extension group, age and size that move files into subfolders or the Recycle Bin
- Dry-run preview showing exactly what would move before anything happens
- Undo log for the last run and per-file restore
- Optional scheduled run while the app is in the tray, skipping files modified in the last N minutes or still downloading
- Works on a user-chosen folder, including a relocated Downloads folder

## Non-goals

- No permanent deletion
- No cloud storage integration
- No duplicate detection or content analysis
